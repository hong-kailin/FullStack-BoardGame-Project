# 特权系统规则拆解

## 规则概述
特权是一种特殊资源，玩家可以消耗特权从版图上拿取任意 1 个非黄金标记。

## 规则细则

### R-PR-01：使用特权
- 玩家消耗 1 个特权，从版图拿取任意 1 个非黄金标记
- 特权数 -1，版图上的特权可用数 +1
- 拿取的标记加入玩家手中

### R-PR-02：特权转移规则
- 当"对手获得特权"触发时：
  - 如果版图上还有可用特权（privilegesAvailable > 0）→ 从版图拿，privilegesAvailable -1
  - 如果版图无可用特权，但对手有特权 → 从对手处抢 1 个
  - 如果双方都没有 → 无事发生

### R-PR-03：特权上限
- 每个玩家最多持有 3 个特权
- 获得特权时如果已有 3 个，无事发生

### R-PR-04：使用特权后标记超上限
- 使用特权拿取标记后，如果标记超过 10 个，需要归还

## 测试点

| 编号 | 测试点 | 对应规则 |
|------|--------|----------|
| PR-01 | 使用特权拿取 1 个红色标记 → 特权 -1，标记 +1 | R-PR-01 |
| PR-02 | 版图有特权 → 从版图分配 | R-PR-02 |
| PR-03 | 版图无特权，对手有 → 从对手抢夺 | R-PR-02 |
| PR-04 | 双方都无特权 → 无事发生 | R-PR-02 |
| PR-05 | 已有 3 个特权 → 再获得时不变 | R-PR-03 |
| PR-06 | 使用特权后标记超 10 → 需要归还 | R-PR-04 |
