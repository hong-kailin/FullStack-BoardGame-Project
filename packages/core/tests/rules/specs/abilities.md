# 卡牌能力规则拆解

## 规则概述
部分卡牌拥有特殊能力，购买后立即触发。

## 规则细则

### R-AB-01：额外回合（extra_turn）
- 购买后当前玩家再执行一个回合
- 不切换玩家

### R-AB-02：获得特权（take_privilege）
- 购买后当前玩家获得 1 个特权
- 受特权转移规则和上限约束

### R-AB-03：从对手拿标记（take_from_opponent）
- 购买后从对手处随机拿取 1 个非黄金标记
- 对手该颜色标记 -1，当前玩家 +1
- 如果对手没有非黄金标记，无事发生

### R-AB-04：拿取同色标记（take_matching_token）
- 购买后从版图上拿取 1 个与卡牌同色的标记
- 如果版图上没有该颜色标记，无事发生

## 测试点

| 编号 | 测试点 | 对应规则 |
|------|--------|----------|
| AB-01 | 购买 extra_turn 卡牌 → 回合不切换 | R-AB-01 |
| AB-02 | 购买 take_privilege 卡牌 → 获得 1 特权 | R-AB-02 |
| AB-03 | 购买 take_from_opponent 卡牌 → 从对手拿标记 | R-AB-03 |
| AB-04 | 对手无标记 → take_from_opponent 无事发生 | R-AB-03 |
| AB-05 | 购买 take_matching_token 卡牌 → 拿取同色标记 | R-AB-04 |
| AB-06 | 版图无同色标记 → take_matching_token 无事发生 | R-AB-04 |
