# 拿取标记规则拆解

## 规则概述
玩家从版图上拿取 1-3 个相邻且位于同一条直线（水平/垂直/对角线）上的非黄金标记。

## 规则细则

### R-TT-01：基本拿取
- 玩家可以拿取 1 个非黄金标记
- 标记从版图移除，加入玩家手中
- 拿取后回合切换到对手

### R-TT-02：拿取多个标记
- 玩家可以拿取 2-3 个相邻且共线的非黄金标记
- 标记必须位于同一条直线（水平/垂直/对角线）
- 标记之间不能有空格或黄金标记隔断

### R-TT-03：3 同色触发对手特权
- 拿取 3 个标记且颜色全部相同时，对手获得 1 个特权
- 对手特权数 +1（受特权上限和转移规则约束）

### R-TT-04：2 珍珠触发对手特权
- 拿取 2 个珍珠标记时，对手获得 1 个特权
- 对手特权数 +1（受特权上限和转移规则约束）

### R-TT-05：不同色不触发特权
- 拿取 2-3 个不同颜色的标记时，对手不获得特权

### R-TT-06：标记超上限需归还
- 拿取后玩家标记总数超过 10 个时，需要归还超出的部分
- 归还的标记放回袋子
- 归还后才切换回合

### R-TT-07：不能拿取黄金
- 拿取标记操作不能包含黄金标记
- 黄金只能通过"拿取黄金+保留卡牌"操作获取

## 测试点

| 编号 | 测试点 | 对应规则 |
|------|--------|----------|
| TT-01 | 拿取 1 个红色标记 → 版图移除、玩家获得、回合切换 | R-TT-01 |
| TT-02 | 拿取 3 个相邻共线的标记 → 全部拿到 | R-TT-02 |
| TT-03 | 拿取 3 个红色标记 → 对手特权 +1 | R-TT-03 |
| TT-04 | 拿取 2 个珍珠 → 对手特权 +1 | R-TT-04 |
| TT-05 | 拿取 2 个不同色标记 → 对手特权不变 | R-TT-05 |
| TT-06 | 拿取后标记 11 个 → needsDiscard = 1 | R-TT-06 |
| TT-07 | 拿取后标记 10 个 → needsDiscard = 0 | R-TT-06 |
| TT-08 | 尝试拿取黄金 → 不在拿取标记的范围内（由前端拦截） | R-TT-07 |
