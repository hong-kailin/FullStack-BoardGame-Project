# 皇室卡牌规则拆解

## 规则概述
玩家达到特定王冠数门槛时，可以从可用皇室卡牌中任选一张并获得其分数和能力。

## 规则细则

### R-RC-01：3 王冠触发
- 玩家购买卡牌后总王冠数 ≥ 3，且未领取过 3 王冠奖励
- 设置 pendingRoyalThresholds 包含 3
- 前端显示选择面板，玩家从可用皇室卡牌中任选一张

### R-RC-02：6 王冠触发
- 玩家购买卡牌后总王冠数 ≥ 6，且未领取过 6 王冠奖励
- 设置 pendingRoyalThresholds 包含 6
- 前端显示选择面板，玩家从剩余皇室卡牌中任选一张

### R-RC-03：选择皇室卡牌
- 玩家选择后，卡牌加入玩家 royalCards
- 该卡牌从 availableRoyalCards 中移除
- 结算卡牌的能力（如果有）
- 记录已领取的门槛（claimedRoyalThresholds）

### R-RC-04：跳过门槛
- 如果玩家从 2 王冠直接跳到 5 王冠，跳过 3 王冠门槛
- 则第 1 张皇室卡牌永久错过（门槛未记录为已领取，但也不会再触发）

## 测试点

| 编号 | 测试点 | 对应规则 |
|------|--------|----------|
| RC-01 | 购买卡牌后王冠数从 2 到 3 → pendingRoyalThresholds 包含 3 | R-RC-01 |
| RC-02 | 选择皇室卡牌 → 卡牌加入玩家、从可用列表移除 | R-RC-03 |
| RC-03 | 选择有能力的皇室卡牌 → 能力被结算 | R-RC-03 |
| RC-04 | 再次达到 3 王冠 → 不重复触发（已领取） | R-RC-01 |
