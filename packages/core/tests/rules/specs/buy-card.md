# 购买卡牌规则拆解

## 规则概述
玩家从金字塔或保留区购买一张珠宝卡牌，用标记支付费用，获得卡牌提供的声望点、王冠、奖励和能力。

## 规则细则

### R-BC-01：基本购买
- 玩家可以从金字塔中选择一张卡牌购买
- 玩家也可以从自己的保留区中选择一张卡牌购买
- 购买后卡牌加入玩家手牌

### R-BC-02：费用计算
- 卡牌费用由 `cost` 字段指定（6 种颜色/珍珠）
- 玩家持有的同色奖励（bonus）自动抵扣对应颜色的费用
- 黄金标记可代替任意颜色/珍珠支付

### R-BC-02b：万能奖励（gem: "any"）
- 购买 `gem: "any"` 的卡牌后，游戏暂停，玩家必须选择一种颜色
- 选择后卡牌的 `gem` 更新为所选颜色，之后正常提供该颜色的奖励
- 在玩家选择颜色之前，该卡牌不提供任何奖励

### R-BC-03：宝石不足不能购买
- 玩家持有的标记 + 黄金万能抵扣不足以支付费用时，购买失败
- 状态不变，返回错误消息

### R-BC-04：购买后标记进袋子
- 花费的标记放回袋子（bag）
- 包括普通标记和黄金标记

### R-BC-05：购买后金字塔补牌
- 从金字塔购买的卡牌被移除后，从对应等级的牌库补充新卡
- 等级 1 保持 5 张展示、等级 2 保持 4 张、等级 3 保持 3 张
- 牌库为空时不补牌

### R-BC-06：购买后切换玩家
- 购买成功后回合切换到对手
- 除非购买的卡牌能力为"额外回合"

### R-BC-07：从保留区购买
- 从保留区购买时，卡牌从保留区移除
- 金字塔不补牌（卡牌本来就不在金字塔中）

## 测试点

| 编号 | 测试点 | 对应规则 |
|------|--------|----------|
| BC-01 | 宝石足够 → 购买成功，卡牌加入手牌 | R-BC-01 |
| BC-02 | 宝石不足 → 购买失败，状态不变 | R-BC-03 |
| BC-03 | 使用黄金万能抵扣完成购买 | R-BC-02 |
| BC-04 | 使用奖励折扣减少费用 | R-BC-02 |
| BC-05 | 购买 gem:any 卡牌 → 暂停等待选择颜色 | R-BC-02b |
| BC-05b | 选择颜色后卡牌 gem 更新为所选颜色 | R-BC-02b |
| BC-06 | 购买后花费的标记进入袋子 | R-BC-04 |
| BC-07 | 购买后金字塔补牌 | R-BC-05 |
| BC-08 | 购买后回合切换到对手 | R-BC-06 |
| BC-09 | 从保留区购买 → 保留区移除该卡牌 | R-BC-07 |
