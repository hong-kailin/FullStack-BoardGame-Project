# 第 14 课：用 HTML 搭游戏界面

## 本节课目标

用 `<div>` 划分游戏页面的区域，用 `<ul>` 显示卡牌列表，搭出游戏页面的 HTML 骨架。

---

## 1. 新标签：`<div>`

`<div>` 是最常用的 HTML 标签——它本身没有任何样式，就是一个"容器"，用来把相关内容包在一起。

```html
<div>
  <h1>璀璨宝石对决</h1>
  <p>双人对战</p>
</div>
```

你可以把 `<div>` 想象成 C++ 里的 `{}` 代码块——它把一组相关的代码包在一起。只不过 HTML 的 `<div>` 是给页面内容分组的。

### 1.1 为什么需要容器？

想象一下，如果没有 `<div>`，你的页面就是平铺的：

```html
<h1>璀璨宝石对决</h1>
<p>当前回合：玩家 1</p>
<h2>版图</h2>
<p>（这里放 5x5 版图）</p>
<h2>金字塔</h2>
<ul>...</ul>
<h2>玩家 1</h2>
<p>...</p>
<h2>玩家 2</h2>
<p>...</p>
```

所有标签从上到下依次排列，没有"分组"的概念。

但后面你要做这些事情：

1. **用 JS 更新版图** — 你得知道"版图区域"是哪个，不能把标题也一起更新了
2. **用 CSS 让玩家 1 和玩家 2 左右并排** — 没有容器包着，你没法告诉浏览器"这两个是一组，让它们并排"
3. **隐藏/显示某个区域** — 比如游戏结束后显示胜利信息，你需要一个容器来整体控制

`<div>` 就是用来解决这个问题的——它把**逻辑上相关的元素包在一起**，形成一个"组"。后面无论是 JS 操作还是 CSS 布局，都是针对这个"组"来做的。

**一句话**：`<div>` 是给页面内容"打包"用的，就像你用文件夹把相关的文件放在一起。

## 2. 新标签：`<ul>` 和 `<li>`

`<ul>` 是无序列表（unordered list），`<li>` 是列表项（list item）。

```html
<ul>
  <li>红宝石 x3</li>
  <li>蓝宝石 x2</li>
  <li>绿宝石 x1</li>
</ul>
```

效果就是 Markdown 中的：

```markdown
- 红宝石 x3
- 蓝宝石 x2
- 绿宝石 x1
```

## 4. 你学到了什么

| 标签 | 作用 | Markdown 类比 |
|------|------|---------------|
| `<div>` | 容器，把相关内容分组 | 没有直接对应，像代码块 `{}` |
| `<ul>` | 无序列表 | `- 列表项` |
| `<li>` | 列表中的一项 | 每行一个 `-` |
| `<h2>` | 二级标题 | `## 标题` |

HTML 只有结构，没有样式——所以页面看起来就是白底黑字，很正常。后面学 CSS 再让它变好看。
