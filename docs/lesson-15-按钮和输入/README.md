# 第 15 课：按钮和输入

## 本节课目标

学会用 `<button>` 和 `<input>` 标签，在页面底部加一个输入框和按钮。

---

## 1. 新标签：`<button>`

```html
<button>开始游戏</button>
```

`<button>` 会在页面上显示一个可点击的按钮。按钮上的文字写在标签中间。

---

## 2. 新标签：`<input>`

```html
<input type="text" placeholder="输入坐标，如 2,2">
```

`<input>` 是输入框。几个常用的 `type`：

| type | 效果 |
|------|------|
| `text` | 文本输入框 |
| `number` | 数字输入框（带上下箭头） |
| `password` | 密码输入框（文字变圆点） |

`placeholder` 是输入框里的灰色提示文字，用户一打字就消失。

---
