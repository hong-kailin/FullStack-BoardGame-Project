# 02. 组件与状态

## 1. 什么是组件？

组件是页面上一个**独立的、可复用的代码块**。在 React 中，组件就是一个函数，它返回一段 JSX。

```tsx
function App() {
  return (
    <div>
      <h1>璀璨宝石对决</h1>
    </div>
  );
}
```

这个 `App` 函数就是一个组件。它返回的 JSX 就是页面要显示的内容。

## 2. 组件函数的结构

```tsx
function App() {
  // 这里写 JavaScript 逻辑
  const [count, setCount] = useState(0)

  // 这里返回 JSX
  return (
    <>
      <h1>Get started</h1>
      <button>Count is {count}</button>
    </>
  )
}

export default App
```

| 部分 | 作用 |
|------|------|
| `function App()` | 定义组件函数 |
| `const [count, setCount] = useState(0)` | 组件的"记忆"——状态 |
| `return (...)` | 返回要显示的 JSX |
| `export default App` | 导出组件，让其他文件能引用 |

## 3. 什么是状态（useState）？

`useState` 是 React 提供的一个函数，让组件能"记住"数据。

```tsx
const [count, setCount] = useState(0)
```

- `count`：当前值（读数据）
- `setCount`：修改值的函数（写数据）
- `useState(0)`：初始值为 0

**类比**：就像 `let count = 0`，但多了一个 `setCount` 函数。调用 `setCount(新值)` 时，React 会自动重新渲染组件，页面上的数字就会更新。

## 4. 为什么不用普通变量？

```tsx
function App() {
  let count = 0;  // 普通变量

  return (
    <button onClick={() => { count = count + 1; }}>
      Count is {count}
    </button>
  );
}
```

这样写，点击按钮后 `count` 确实变成了 1，但**页面不会更新**。因为 React 不知道你改了数据。

`useState` 的作用就是：**告诉 React"这个数据变了，请重新渲染"**。

## 5. Fragment（`<>...</>`）

```tsx
return (
  <>
    <h1>标题</h1>
    <p>段落</p>
  </>
)
```

一个组件只能返回一个根元素。如果你想返回多个并列的元素，用 `<>` 把它们包起来。

`<>` 是 Fragment 的简写，它不会在 DOM 中产生多余的 div。

## 6. 一句话总结

**组件 = 函数 + 状态 + JSX。`useState` 让组件有记忆，数据变了页面自动更新。**
