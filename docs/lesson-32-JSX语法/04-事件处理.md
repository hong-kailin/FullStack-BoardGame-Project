# 04. 事件处理

## 1. 在 JSX 中绑定事件

```tsx
<button
  type="button"
  className="counter"
  onClick={() => setCount((count) => count + 1)}
>
  Count is {count}
</button>
```

## 2. `onClick` 而不是 `onclick`

在 HTML 中，点击事件用 `onclick`（全小写）：

```html
<button onclick="handleClick()">点我</button>
```

在 JSX 中，用 `onClick`（驼峰命名）：

```tsx
<button onClick={handleClick}>点我</button>
```

类似的还有：

| HTML | JSX |
|------|-----|
| `onclick` | `onClick` |
| `onchange` | `onChange` |
| `onsubmit` | `onSubmit` |
| `onmouseenter` | `onMouseEnter` |
| `onkeydown` | `onKeyDown` |

规律：**去掉 on，剩下的单词首字母大写**。

## 3. `onClick` 的值必须是一个函数

```tsx
// ✅ 正确：onClick 的值是一个函数
onClick={() => setCount(count + 1)}

// ✅ 也正确：onClick 的值是一个函数名
onClick={handleClick}

// ❌ 错误：onClick 的值是函数调用的结果
onClick={setCount(count + 1)}
```

第三个为什么错？因为 `setCount(count + 1)` 会**立即执行**，而不是等点击时才执行。`onClick` 期望的是一个"等点击时再调用"的函数，而不是"现在执行"的结果。

## 4. 箭头函数

```tsx
onClick={() => setCount(count + 1)}
```

`() => setCount(count + 1)` 是一个箭头函数。它的意思是：**定义一个函数，这个函数的内容是 `setCount(count + 1)`，但先不执行，等点击时才执行**。

**类比**：就像你写了一张便利贴"帮我做这件事"，贴在那里，等需要的时候才有人去做。箭头函数就是那张便利贴。

## 5. `{count}` 显示变量值

```tsx
Count is {count}
```

`{count}` 会把 count 的当前值显示在按钮文字中。每次点击按钮，`setCount` 修改 count，React 自动重新渲染，页面上的数字就会更新。

## 6. 完整流程

1. 用户点击按钮
2. React 调用 `onClick` 中的函数
3. 函数执行 `setCount(count + 1)`
4. React 发现 count 变了
5. React 自动重新调用 `App()` 函数
6. 新的 JSX 中 `{count}` 变成了新值
7. 页面更新

## 7. 一句话总结

**`onClick` 的值必须是一个函数，用箭头函数包一层是最常见的写法。**
