## 本节课目标

掌握最常用的终端命令，确保开发环境就绪。

## 1. 终端是什么？

终端（Terminal）是一个让你用**文本命令**和电脑交互的工具。平时你用鼠标点文件夹、打开文件、复制粘贴，在终端里都用命令来完成。

> 类比：图形界面（鼠标点）≈ 开自动挡汽车；终端（敲命令）≈ 开手动挡汽车。手动挡看起来麻烦，但操控更精确、更强大。作为开发者，终端是必备技能。

macOS 自带的终端叫"终端.app"（Terminal），你也可以装 iTerm2（更强大，但不是必须的）。

## 2. 最常用的命令

以下是你日常开发中会用到的命令。不需要背，多用几次就记住了。

### 2.1 文件和目录操作

| 命令 | 含义 | 类比 |
|------|------|------|
| `pwd` | 显示当前目录路径 | 我在哪？ |
| `ls` | 列出当前目录的文件 | 看看这有什么 |
| `ls -la` | 列出所有文件（包括隐藏的），详细信息 | 详细看看有什么 |
| `cd 目录名` | 进入某个目录 | 去这个文件夹 |
| `cd ..` | 返回上级目录 | 回去 |
| `mkdir 目录名` | 创建新目录 | 新建文件夹 |
| `touch 文件名` | 创建空文件 | 新建文件 |
| `cp 源 目标` | 复制文件 | 复制粘贴 |
| `mv 源 目标` | 移动/重命名文件 | 剪切粘贴 |
| `rm 文件名` | 删除文件 | 删除 |
| `rm -rf 目录名` | 删除目录及其所有内容 | 彻底删除文件夹 |

**注意**：`rm -rf` 很危险，没有回收站，删了就没了。用的时候确认路径正确。

### 2.2 查看文件内容

| 命令 | 含义 |
|------|------|
| `cat 文件名` | 把文件内容打印到终端 |
| `head 文件名` | 只看文件前 10 行 |
| `tail 文件名` | 只看文件后 10 行 |
| `less 文件名` | 分页查看（按 q 退出） |

### 2.3 路径相关

```
.   当前目录
..  上级目录
~   你的 home 目录（/Users/你的用户名）
/   根目录
```

## 3. 动手练习

打开终端，跟着做一遍：

```bash
# 1. 看看你在哪
pwd

# 2. 回到 home 目录
cd ~
pwd

# 3. 去项目目录（改成你的实际路径）
cd /Users/hongkailin/Desktop/FullStack-BoardGame-Project

# 4. 看看项目里有什么
ls -la

# 5. 创建一个临时目录练手
mkdir temp-test

# 6. 进入并创建文件
cd temp-test
touch test.txt

# 7. 查看目录内容
ls -la

# 8. 返回上级目录，删除临时目录
cd ..
rm -rf temp-test
```

## 4. 验证开发环境

确保以下命令都能正常输出：

```bash
# Node.js 版本
node --version
# 输出: v22.22.1

# npm 版本
npm --version
# 输出: 10.9.4

# tsx 版本
tsx --version
# 输出: v4.19.0

# git 版本
git --version
# 输出: git 2.x.x
```

如果哪个命令提示"command not found"，说明对应的工具没装好：

| 工具 | 安装方式 |
|------|---------|
| Node.js / npm | 从 [nodejs.org](https://nodejs.org) 下载安装 |
| tsx | `npm install -g tsx` |
| git | 从 [git-scm.com](https://git-scm.com) 下载安装，或 `brew install git` |

## 6. 让终端更好用（可选）

### 6.1 Tab 键自动补全

输入命令或路径时按 `Tab`，终端会自动补全。比如输入 `cd Do` 然后按 Tab → `cd Documents/`。

### 6.2 上下箭头查看历史

按 `↑` 键可以找回之前执行过的命令，不用重新打。

### 6.3 `Ctrl + C` 中断

如果某个命令卡住了或跑个没完，按 `Ctrl + C` 强制终止。

### 6.4 用 `code .` 在 VS Code 中打开当前目录

在终端中进入项目目录，然后执行：

```bash
code .
```

就会在当前目录打开 VS Code。如果你没装这个命令，可以在 VS Code 里按 `Cmd + Shift + P`，输入"shell command"，选择"Install 'code' command in PATH"。

## 7. 总结

| 命令/操作 | 用途 |
|-----------|------|
| `cd`、`ls`、`mkdir`、`touch` | 文件和目录操作 |
| `cat`、`head`、`tail` | 查看文件内容 |
| `node --version` 等 | 验证环境 |
| `Tab` 键 | 自动补全 |
| `↑` 键 | 历史命令 |

| `code .` | 在 VS Code 中打开当前目录 |

## 思考题（附答案）

1. **`rm -rf` 为什么危险？**
   - 答：`rm` 删除，`-r` 递归删除目录内所有内容，`-f` 强制删除（不询问确认）。三个组合起来 = "把这里的一切彻底摧毁，不问你确认"。没有回收站，删了就找不回来了。

2. **`cd ~` 和 `cd /` 有什么区别？**
   - 答：`cd ~` 回到用户 home 目录（`/Users/你的用户名`），`cd /` 回到系统根目录。

3. **`ls` 和 `ls -la` 有什么区别？**
   - 答：`ls` 只显示文件名；`ls -la` 显示所有文件（包括 `.` 开头的隐藏文件），并展示权限、大小、修改时间等详细信息。
