# 第 13 课：我的第一个 HTML 页面

## 本节课目标

创建一个最简单的 HTML 页面，在浏览器中显示"璀璨宝石对决"的标题。

---

## 1. HTML 是什么？

HTML（超文本标记语言）是用来**给文字加结构**的。你已经在用它的"简化版"了——Markdown。

看看这个对比：

| 效果 | Markdown | HTML |
|------|----------|------|
| 一级标题 | `# 标题` | `<h1>标题</h1>` |
| 二级标题 | `## 标题` | `<h2>标题</h2>` |
| 段落 | 直接写文字 | `<p>文字</p>` |

**核心区别**：Markdown 用符号（`#`、`*`），HTML 用**标签**（`<h1>`、`<p>`）。

---

## 2. 一个最简单的 HTML 文件

```html
<h1>璀璨宝石对决</h1>
<p>欢迎来到璀璨宝石对决！</p>
```

就这么简单。`<h1>` 是一级标题，`<p>` 是段落。

---

## 3. 动手

创建 `docs/lesson-13-我的第一个HTML页面/index.html`：

```html
<h1>璀璨宝石对决</h1>
<p>欢迎来到璀璨宝石对决！</p>
```

然后**双击这个文件**，它会在浏览器中打开。

---

## 4. 浏览器开发者工具

按 `F12` 或 `Cmd + Option + I` 打开开发者工具，点击 **Elements（元素）** 标签，可以看到页面的 HTML 结构。

---
